# Support

Use the issue tracker of the repository that owns the affected component:

- [delphi-edm4hep issues](https://github.com/delphi-fullDST-edm4hep/delphi-edm4hep/issues)
- [delphi-sim-pipeline issues](https://github.com/delphi-fullDST-edm4hep/delphi-sim-pipeline/issues)
- [delphi-edm4hep-eventdisplay issues](https://github.com/delphi-fullDST-edm4hep/delphi-edm4hep-eventdisplay/issues)

Before opening an issue, search for an existing report and collect the repository
revision, environment versions, exact command and relevant logs. Remove secrets,
private paths and restricted data from anything you post publicly.

This is a research software project maintained on a best-effort basis; no
response-time guarantee is provided.
